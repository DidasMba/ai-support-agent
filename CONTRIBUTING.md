# Contributing

Thank you for helping! All skill levels are welcome.

## Setup
Follow the Quickstart in the README, then create a branch: `git checkout -b my-change`.

## Pull requests
- Keep one change per PR and describe what and why
- Never include real business data or API keys
- Add or update docs if behaviour changes

## Good places to start
See the `good first issue` label on GitHub, or `docs/good-first-issues.md` in this repo.

## Conduct
Be respectful. See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
